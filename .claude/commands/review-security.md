# Revisão de segurança

Revise a mudança atual procurando:
- autorização horizontal e vertical;
- exposição de PII;
- validação de entrada;
- armazenamento de tokens;
- injection e SSRF;
- replay/idempotência de webhook;
- rate limiting;
- auditoria;
- falhas abertas por padrão;
- logs com dados sensíveis.

Retorne achados por severidade, arquivo/linha, impacto e correção recomendada. Não altere o código até apresentar os achados.
